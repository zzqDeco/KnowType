# Input Source Single Source Model

## Status

Absorbed

## Summary

This plan attempted to collapse KnowType to a single non-mode-enabled macOS Text Input Source. Local acceptance showed that the parent-only source could appear in System Settings while still not becoming a switchable menu-bar input source. It is absorbed by `input-source-menu-visible-mode-registration.plan.md`, which restores the parent plus visible `.Hans` input mode model.

## Scope

This record is retained only as branch archaeology for the reverted direction.

## Behavior

- Replaced by the parent plus visible `.Hans` model.
